# 数字收据打印机 Digital Receipt Printer

一个纯前端的网页小玩具：模拟"支付完成后，热敏打印机吐出电子收据"的动画效果。

**🔗 在线演示：<https://liyucheng1997.github.io/296_lab-digital-receipt/>**

单文件、零依赖，双击 `index.html` 即可运行。

## 功能

- 💳 **模拟支付流程**：确认订单 → 支付中 → 打印收据
- 🖨 **拟真打印机**：LCD 状态屏（打印进度百分比）、STATUS 指示灯、FEED 走纸键、散热格栅、金属切纸口，打印时机身轻微震动
- 📜 **平滑吐纸动画**：基于 `transform` 的 GPU 加速动画，出纸时长随收据长度自适应
- 🎨 **4 种可切换的收据样式**：
  - **经典** — 等宽字体 + 条形码
  - **小票** — 便利店多商品明细
  - **复古** — 米黄纸、衬线字体、红色"已支付"印章
  - **极简** — 大号金额排版 + 按订单号生成的伪二维码
- 🔁 打印完成后可切换样式重新打印（纸张缩回 → 重新吐出）
- 🖨️ 支持调用浏览器真实打印（只输出收据部分）

## 技术

原生 HTML / CSS / JavaScript，无任何构建步骤与依赖。

- 收据锯齿撕边：CSS `clip-path`
- 条形码 / 热敏纸横纹：CSS `repeating-linear-gradient`
- 伪二维码：由订单号播种的 SVG（纯装饰，不可扫描）
